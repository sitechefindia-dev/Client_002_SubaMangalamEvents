# Suba Mangalam Events — Client Website

Production-ready, highly responsive, SEO-optimized 6-page website for **Suba Mangalam Events**, Coimbatore's leading event management and catering company.

## Project Structure
- `index.html`: Home page with Hero banner, quick package quote estimator, service highlights, reviews & FAQs.
- `about.html`: Brand story, core values, team, and 100% stress-free event commitment.
- `services.html`: Full catering & event management catalog (Valamaram Pandhal, Stage Decor, South/North Indian Feasts, DJ, Entry Effects, Luxury Cars).
- `gallery.html`: Filterable photo/video portfolio (Weddings, Receptions, Stage Decor, Feasts).
- `pricing.html`: Transparent event packages (Silver, Gold, Royal Diamond) & interactive package estimator tool.
- `contact.html`: Interactive lead booking form, contact details, Google Map embed, & direct WhatsApp CTA (+91 9025769906).
- `css/styles.css`: Custom CSS design system (Maroon & Gold theme, Glassmorphism, animations).
- `js/main.js`: Interactive JS components (Package calculator, Gallery filter, Accordions, WhatsApp payload builder).
